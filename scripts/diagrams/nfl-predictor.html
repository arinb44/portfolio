NFL Game Predictor · how it fits together

From play-by-play to a weekly pick

Data

Public data

  • nflverse: play-by-play, schedules, rosters, injury reports, 2006–now
  • Open-Meteo: game-time weather
  • data_loader.py weather.py
→

Features

Home minus away

  • EPA, success rate, Elo, QB form
  • Missing players, travel, fatigue, weather matchups
  • Only pre-kickoff information
  • features.py elo.py players.py situational.py
→

Model

Logistic regression

  • Walk-forward: train to season N, test N+1
  • Beat random forest and gradient boosting on log loss
  • train.py evaluate.py
→

Output

Picks with reasons

  • Win probability and spread per game
  • Exact factor waterfall from 50%
  • Streamlit dashboard, in the browser on GitHub Pages
  • explain.py predict.py dashboard.py
Runs itself. A scheduled job refreshes the data and predicts on Thursday, Sunday and Monday, then commits the picks before kickoff.
